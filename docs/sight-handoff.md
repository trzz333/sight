**Notes:**

- Transport module: `src/sight_agent/rl/godot_transport.py`. Class `GodotH3Transport`. Three exception classes: `GodotTransportError` (socket / framing / OS), `GodotProtocolError` (wire-shape violation: wrong type, missing required field, run_id / episode_id / seq mismatch, malformed JSON, invalid `terminal_reason`, malformed `obs`), `GodotRemoteError` (Godot replied with `type="error"`, carries `code` / `message` / raw `payload`).
