**Notes:**

- **H4 Step 2 wire contract.** `reset` request optionally carries `observation_mode` + `pixel_width/height/channels`. Defaults preserve H3 byte-compat. Senders must send all four together or none; partial sets are protocol errors on both Python and Godot sides. Pixel response payload is a dict with `mode, shape, dtype, encoding, data, pixel_source, capture_point, headless_allowed, viewport_width, viewport_height`. Encoding is `flat_uint8` for now; `base64` is the documented post-acceptance optimization slot.
- **H4 Step 2 failure mode for pixel.** Godot rejects pixel/both at reset with `ERROR_BAD_REQUEST` until Step 3 lands. This is intentional: emitting `obs.data` from Godot before a real viewport capture exists would be synthetic raster, which the Grok H3 closure caveats and the H4 plan Decision 2 explicitly bar without Jeff approval. The Python pixel-obs validation can still be exercised end-to-end via FakeGodotServer.
