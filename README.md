# Sight

Sight is a local-first reinforcement-learning lab: a hobby and portfolio project for learning modern RL by training small policies, from scratch, on a single older gaming laptop. It is not a product, a startup, or a QA tool. Success is defined by learning progress and reproducible local training, not by users, revenue, or downstream commercial intent.

The current substrate is **Signal Dodge**, a custom Godot micro-game owned by this repo, exposed as a Gym-style environment with state observations. Policies are scored against a constant-action baseline (mean episode length 930.27); because that baseline is itself a fixed action, any policy that clears it has to actually dodge rather than stand still. Gymnasium classic-control environments are used alongside it for formal grounding.

**Non-goals, stated up front and permanently.** Sight does not target live commercial games. It does not touch Freecash, offerwalls, or any paid-engagement platform. It does not develop bot-detection evasion, account farming, or identity spoofing. It does not produce assets or tooling that could drop into a live-service cheat pipeline. These are not current priorities or performance constraints; they are permanent project boundaries. PRs that cross them are closed without review. See `docs/ethics.md` and `CONTRIBUTING.md`.

**Where it is now.** The interesting finding so far is about dependability, not peak score. A from-scratch RL policy (NoisyNet QR-DQN) *can* clear the baseline, but only on a minority of training seeds at a 200k-step budget, so it is reported honestly as an across-seed distribution from multi-seed runs with interval estimates (interquartile mean plus bootstrap confidence intervals, in the style of Agarwal et al. 2021 / rliable) rather than from a single lucky seed. Imitation learning (behavioral cloning) and PPO fine-tuning clear the baseline reliably. The decisive variable for from-scratch learning turned out to be the exploration mechanism: epsilon-greedy collapsed every architecture into a single-action basin on this provably symmetric env, and replacing it with NoisyNet weight-noise exploration was what first produced competent dodging.

**Methods exercised.** Value-based RL (DQN), distributional RL (QR-DQN), NoisyNet exploration, imitation learning (BC), policy-gradient fine-tuning (PPO), and a self-supervised / model-based track that adds a next-state prediction objective on a shared encoder (the world-model idea, adapted to a low-dimensional state env: predict the next state directly). Logging is structured NDJSON with deterministic seeds; evaluation tracks reward, episode length, action distribution, and a growing failure taxonomy. State observations come first; pixel observations and a small CNN are a later phase.

The project is solo and single-voice: one author makes the engineering calls, with an evidence-anchored self-audit (verify every load-bearing claim against on-disk artifacts and re-run the evals) standing in for external review. See `docs/sight-charter.md` for scope, phase gates, success criteria, and decision authority, and `docs/sight-handoff.md` for live status.
