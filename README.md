# Sight

Sight is a local-first AI game-agent lab. It is a research and portfolio project that builds agents which perceive game state, decide actions, execute them, and improve through measurement. The target environments are custom Godot micro-games, open-source games where automation is explicitly permitted, and formal RL benchmark environments via Gymnasium. Nothing in this repository is intended to run against a platform where automation is prohibited.

**Non-goals, stated up front and permanently.** Sight does not target live commercial games. It does not touch Freecash, offerwalls, or any paid-engagement platform. It does not develop bot-detection evasion, account farming, or identity spoofing. It does not produce assets or tooling that could drop into a live-service cheat pipeline. These are not performance constraints or current priorities. They are permanent project boundaries. PRs that cross them will be closed without review. See `docs/ethics.md` and `CONTRIBUTING.md`.

The research posture is deliberate. Game-playing agents are a well-established AI research tradition with public benchmarks, published papers, and shipping commercial products. Sight sits in that tradition. The value is a clean, reproducible agent loop against environments where the measurement is honest and the ethics are unambiguous. Custom Godot games give a controlled substrate. Open-source games give ecological variety. Gymnasium gives formal credibility. The combination lets the project progress publicly without either the appearance or the reality of crossing into abuse.

The system is modular by design. Perception starts with OpenCV template matching and only escalates to a small vision model when template matching provably fails. Policy starts rule-based and only takes on learning components once the loop is reliable end-to-end. Logging is structured NDJSON. Evaluation tracks win rate, episode length, action distribution, and a growing failure taxonomy. A Council deliberation layer (separate project, optional integration) can be wired in during later phases for harder decisions. Everything runs locally on modest hardware. See `docs/sight-charter.md` for scope, phase gates, success criteria, and decision authority.
